# Publicar no GitHub Pages — sem terminal

1. Entre em github.com e crie um repositório chamado `python-arcadia`.
2. Deixe o repositório **Public** se estiver usando GitHub Free.
3. Na tela do repositório, use **Add file → Upload files**.
4. Extraia o ZIP deste curso no computador e arraste **os arquivos de dentro da pasta `python-arcadia-web`** para a área de upload. O `index.html` precisa ficar na raiz do repositório.
5. Clique em **Commit changes**.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**.
8. Selecione `main` e `/ (root)` e clique em **Save**.
9. Volte em **Settings → Pages** e use **Visit site** quando o endereço aparecer.

Depois disso, sua rotina normal é abrir o site publicado. Você não precisa estudar pela tela do repositório.
