# Python Arcádia V9 — revisão didática

- Camada **Aula guiada** em todas as 80 aulas conceituais.
- Cada aula agora explica **por que o conceito existe**, um **modelo mental**, execução passo a passo e variações importantes.
- Novo **cheque rápido escrito** antes do desafio: o aluno responde com as próprias palavras e só depois compara com a referência.
- Explicações iniciais são mais detalhadas; os arcos avançados ficam gradualmente mais independentes.
- `for/range`, `while`, listas/`append`, slicing/índices negativos, dicionários, tuplas/sets e padrões de loop foram ampliados diretamente no conteúdo base.
- Modelos mentais genéricos/incorretos de versões antigas foram substituídos por explicações específicas do nível.
- Nenhum progresso, código ou economia é resetado.
