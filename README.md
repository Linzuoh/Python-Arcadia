# Python Arcádia Web

Curso interativo de Python que roda diretamente no navegador. O repositório é a infraestrutura; o aluno estuda pelo GitHub Pages.

## O que existe

- 100 níveis em 10 arcos
- editor Python dentro da página (Ace)
- Python executado no navegador com Pyodide
- correção automática para exercícios
- 10 provas práticas
- 160 cartões de revisão espaçada
- progresso, XP, sequência e conquistas
- conteúdo futuro bloqueado visualmente
- botão que copia o contexto da aula + código + erro para continuar a tutoria no ChatGPT

## Publicar sem terminal

Veja `PUBLICAR_NO_GITHUB.md`.

> Observação: GitHub Pages é hospedagem estática. Os testes ficam ocultos na interface normal, mas uma pessoa que deliberadamente inspecionar o código-fonte do site/repositório consegue encontrá-los. Para uma avaliação com testes realmente secretos seria necessário um backend.


## V5 — Wiki cumulativa

A V5 adiciona uma Wiki que só libera conceitos após a conclusão da aula correspondente. Dentro dos editores, Ctrl/Cmd + clique em uma palavra já aprendida abre a referência contextual. Termos novos da aula atual ficam bloqueados nesse atalho até o nível ser concluído.


## V6 — Maestria e recompensa

A V6 adiciona debugger visual, mapa de maestria, caderno de erros, leitura de código, conserto de bugs, modo Fluência, desafios extras, desafio diário, moedas, nível de jogador, loja cosmética e pets. XP nunca é gasto: ele sobe seu nível. Moedas são obtidas estudando e usadas apenas em cosméticos. Nenhuma mecânica usa dinheiro real ou recompensa aleatória.

O progresso continua no mesmo armazenamento da V4/V5; uma migração adiciona os novos campos sem apagar níveis já concluídos.

## V7 — pets vivos

Pets agora atravessam a tela, têm animações próprias, falam em eventos do curso e podem ser clicados. Cada espécie possui um poder leve de estudo com 3 cargas diárias. Poderes não escrevem código, não revelam testes e ficam desligados em provas e no Modo Fluência.


## V7.2
A inicialização do Python agora é sob demanda. A página nunca depende do Pyodide para abrir ou navegar.

## V8 — revisão ativa e auditoria geral

A V8 adiciona revisão com resposta escrita, diagnóstico de prova somente depois da aprovação, desafios diários cumulativos mais difíceis e variados, novos treinos externos e uma auditoria pedagógica dos 100 níveis. Veja `CHANGELOG_V8.md` e `AUDIT_V8.md`.


## V9 — didática guiada
A V9 mantém o sistema de treino da V8 e adiciona uma camada pedagógica a todas as aulas conceituais: motivação, modelo mental, leitura passo a passo, variações e um mini-check escrito antes do desafio. A resposta de referência só aparece depois da tentativa (ou ao escolher “Não lembro”).
